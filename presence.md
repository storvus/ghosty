# Ghosty Presence Model

## Основные понятия

### Состояние устройства

Устройство может находиться только в одном из двух состояний:

* Online
* Offline

Устройство считается Online только при активном подключении к серверу.

Если все устройства пользователя Offline, пользователь считается Offline.

---

### Статус пользователя

Пока пользователь Online, он может иметь один из статусов:

* Active
* Invisible

Статус привязан к пользователю, а не к устройству.

Если статус меняется на одном устройстве, он немедленно обновляется на всех остальных устройствах пользователя.

---

## Подключение нового устройства

### Если у пользователя уже есть Online-сессия

Новое устройство получает текущий статус пользователя.

Пример:

* Телефон: Online + Invisible
* Ноутбук подключается

Результат:

* Ноутбук получает статус Invisible

---

### Если Online-сессий нет

При подключении используется настройка входа:

* Last Used
* Active
* Invisible
* Ask Every Time

По умолчанию рекомендуется использовать Last Used.

---

## Настройка входа

Пользователь может выбрать один из вариантов:

* Last Used
* Active
* Invisible
* Ask Every Time

### Last Used

Используется последний активный статус пользователя.

### Active

Всегда входить как Active.

### Invisible

Всегда входить как Invisible.

### Ask Every Time

Перед подключением показывать выбор:

* Active
* Invisible

---

## Поведение Offline

В режиме Offline:

* новые сообщения не синхронизируются;
* список чатов не обновляется;
* присутствие других пользователей не обновляется;
* разрешены только push-уведомления.

---

## Push-уведомления

При нажатии на push пользователь обязательно выходит Online.

### Кнопка "Посмотреть"

Подключение выполняется со статусом, определяемым настройкой входа.

Примеры:

* Last Used → используется последний статус;
* Active → вход как Active;
* Invisible → вход как Invisible.

### Кнопка "Посмотреть скрытно"

Подключение выполняется как Invisible независимо от настройки входа.

После подключения статус пользователя становится Invisible на всех устройствах.

---

## Допущения

Ghosty не поддерживает:

* Last Seen;
* Read Receipts ("прочитано");
* любые другие механики подтверждения просмотра сообщений.

Поэтому статус пользователя определяется только:

1. Наличием Online-сессии.
2. Текущим статусом Active или Invisible.
