Ghosty - мессенджер для обмена сообщениями.

Регистрация:
- Пользователь может зарегистрироваться, указав email, никнейм и пароль.

Основные функции:
- Отправка текстовых сообщений
- Наличие статусов:
  - "Онлайн" - пользователь доступен для общения
  - "Отошел" - пользователь временно недоступен
  - "Не беспокоить" - пользователь не хочет быть беспокоимым
  - "Невидимка" - пользователь скрывает свой статус от других
  - "Невидимка с исключением" - пользователь скрывает свой статус от всех, кроме определенных контактов
  - "Оффлайн" - пользователь не в сети
- Список контактов
- Поиск людей по имени, фамилии, никнейму или UID
- Пользователь может заблокировать другого пользователя, чтобы он не мог отправлять ему сообщения
- Пользователь может отметить другого пользователя как "мошенника", чтобы предупредить других пользователей о возможной опасности
  - Если пользователь получает 10 (?) отметок "мошенник", он автоматически блокируется и не может отправлять сообщения другим пользователям
- Смайлик, бьющийся об стену!

Out of scope:
- Нет групповых чатов, только личные сообщения между пользователями
- Нет информации о том, прочитано ли сообщение получателем
- Нет информации о том, когда пользователь был в сети в последний раз

Типы событий:
- Сообщение пришло
- Пользователь изменил статус
- Изменение статуса пользователя. Ключевые моменты:
  - Пользователь изменяет свой статус в момент, когда уже находится в сети:
    - Если пользователь устанавливает статус "Онлайн", "Отошел" или "Не беспокоить"
      - его контакты получают уведомление об изменении его статуса
      - его другие девайсы/сессии синхронизируют новый статус
    - Если пользователь устанавливает статус "Невидимка" или "Невидимка с исключением":
      - его контакты получают уведомление о том, что пользователь Оффлайн
        - контакты из списка исключений получают уведомление о том, что пользователь "Невидимка с исключением" или "Онлайн"
      - его другие девайсы/сессии синхронизируют новый статус
  - Пользователь подключается к сети, уже имея онлайн сессии:
    - новая сессия задает текущий статус пользователя для других сессий
  - Если пользователь разлогинивается == устанавливает статус "Оффлайн"
    - его другие девайсы/сессии НЕ синхронизируют новый статус
    - Остались активные сессии пользователя или пользователь был "Невидимый...":
      - его контакты НЕ получают уведомление об изменении его статуса
    - Активных сессий пользователя не осталось:
      - его контакты получают уведомление о том, что пользователь теперь Оффлайн

- Если пользователь будучи "Невидимкой..." добавляет или удаляет кого-то в список исключений, его контакты получают уведомление об изменении его статуса (Оффлайн или "Невидимка с исключением"/"Онлайн")

REST:
- Получение списка контактов
- Получение списка исключений для статуса "Невидимка с исключением"
- Добавление/удаление контакта
- Добавление/удаление пользователя в список исключений для статуса "Невидимка с исключением"
- Поиск пользователей по имени, фамилии, никнейму или UID
